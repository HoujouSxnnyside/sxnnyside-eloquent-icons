# Support

## Getting Help

**GitHub Issues**
For bugs, inconsistent icons, or unexpected behavior in the demo, open an [issue](https://github.com/sxnnyside-project/sxnnyside-eloquent-icons/issues). Use the appropriate template and include enough context to reproduce the problem.

**Requesting a new icon?** See [CONTRIBUTING.md](CONTRIBUTING.md) — icon requests follow their own lightweight process, separate from bug reports.

---

## Before Asking

- Check the [README](README.md) — installation, usage, and architecture are documented there.
- Check [docs/icon-list.md](docs/icon-list.md) — the icon you need may already exist.
- Search existing [issues](https://github.com/sxnnyside-project/sxnnyside-eloquent-icons/issues) before opening a new one.

---

## What This Isn't

This is not a priority support channel. Response times are not guaranteed.
For security vulnerabilities, see [SECURITY.md](SECURITY.md).
